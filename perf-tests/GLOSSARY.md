# 性能基准上下文

`perf-tests` 工程的语言：什么是一次测量、什么算回归、什么不算。

## Language

**测点**：
一次可命名、可重复的性能采样，id 形如 `<场景>.<参数>`，是报告与 JSON 的稳定键。
_Avoid_: 指标、benchmark 条目

**场景**：
一组共享前置条件的测点集合；失败隔离到场景，不吞掉整份报告。

**桥接基准**：
以合成夹具插件为被测物，测量宿主 ↔ wasm 插件之间的原语与通道开销。
_Avoid_: 平台基准、宿主 benchmark

**应用基准**：
以随包真实业务应用为被测物，测量真实命令链路的端到端耗时。
_Avoid_: 业务基准、app bench

**随包产物**：
平台仓 `resources/plugins/<端>/<plugin-id>/` 下、随产品发布的 wasm 组件与清单；应用基准只加载它，不现场构建。

**冒烟 / 全量**：
冒烟是覆盖每个模块一条主链的最小子集，秒级可跑；全量是完整场景矩阵。两者共用同一套测点 id。

**数量级门禁**：
以「慢一个数量级」为红线的宽松门限，不是精确回归线；机器差异不应触发，链路退化必须触发。
_Avoid_: 阈值、性能断言

**无头语义**：
不创建 GUI `AppHandle`、不弹窗的宿主装配方式；弹窗类授权以预授权替代，依赖窗口或对端推送的路径明确排除在测量范围外。

**常驻 RSS**：
所有被测应用激活并跑完场景后进程的当前驻留集。

**峰值 RSS**：
内核记录的进程生命周期最大驻留集（Linux `VmHWM`）；它不依赖轮询采样，能抓到激活瞬间的短高峰。
